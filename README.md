# nord-forge community defaults

Shared GitHub configuration for nord-forge projects, including Fonn.

Funding setup is prepared for GitHub Sponsors, Buy Me a Coffee and Ko-fi. The accounts and payment pages are not live yet, so funding links remain commented out. Follow the [funding setup guide](docs/funding-setup.md) to create the accounts and activate verified links.

Once enabled, [`.github/FUNDING.yml`](.github/FUNDING.yml) supplies the default Sponsor button for repositories in this organization that do not define their own funding file. Edit the shared file once to update those repositories. GitHub documents [organization-wide community defaults](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) and [supported funding providers](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository).
