# nord-forge community defaults

Shared GitHub configuration for nord-forge projects, including Fonn.

Support nord-forge through [GitHub Sponsors](https://github.com/sponsors/nord-forge). The shared funding file enables this link across eligible repositories. Ko-fi is planned for later; its link and the optional Buy Me a Coffee link remain disabled. See the [funding setup guide](docs/funding-setup.md) to add another verified provider.

[`.github/FUNDING.yml`](.github/FUNDING.yml) supplies the default Sponsor button for repositories in this organization that do not define their own funding file. Edit the shared file once to update those repositories. GitHub documents [organization-wide community defaults](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) and [supported funding providers](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository).
